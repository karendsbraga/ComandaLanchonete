# **🍔 Comanda para Lanchonete em C**

## Em em uma das minhas aulas de Algoritmos e Pensamento Computacional realizei uma atividade que consistia em criar uma comanda para lanchonete.
--------------------------------------------------------------------------------------------


 # Como funciona o código

## O sistema opera por meio de um menu interativo e utiliza lógica estruturada em C:
- Estrutura de Repetição (do/while): Mantém o menu ativo continuamente, permitindo o registro de múltiplos itens no mesmo pedido.

- Estruturas de Decisão (if / else if): Validam a opção escolhida pelo usuário, adicionando o valor do item correspondente ao subtotal da compra.

- Validação de Entrada: Informa o usuário caso um código inválido seja inserido.

- Encerramento (0): Encerra a execução do laço de repetição e exibe o valor total acumulado.
